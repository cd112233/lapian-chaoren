# 完整拉片 V2 字段规范

V2 的基本原则是：**先写画面事实，再写功能判断；先描述发生了什么，再解释为什么有效。**

每一镜都必须填写以下字段。不得因为镜头短、人物不动、画面简单或没有主特效而省略。

## 1. 边界与承接

- `shot_id`：V2 镜头编号。
- `source_in_frame` / `source_out_frame`：以原片 30fps 帧号记录，出点为开区间。
- `source_in` / `source_out` / `duration_sec`：时间码与镜长。
- `boundary_evidence`：切点依据；注明硬切、闪白遮切、运动模糊遮切、甩镜遮切、动作匹配切或连续镜头。
- `previous_shot_result`：上一镜结束时，人物、肢体、视线、能量、场景和运动方向的具体状态。
- `next_shot_bridge`：本镜如何把姿态、视线、力方向、声音或特效尾迹交给下一镜。

## 2. 真实画面

- `opening_frame_literal`：第一帧实际能看见什么，不写抽象功能。
- `screen_layout`：前/中/后景，人物屏幕左右、远近、高低、遮挡和负空间。
- `literal_visual_description`：整镜真实画面叙述，必须覆盖起点、发展、峰值和结尾。
- `end_state`：最后可稳定辨认的姿态、接触、运动方向、能量和环境状态。

## 3. 人物与动作

- `character_positions`：本体、对手、分身分别在画面哪一侧、哪一景深与哪个高度。
- `clone_count_and_positions`：分身数量、归属、透明度、相对本体的位置与是否同步/延迟。
- `body_part_specifics`：明确左右手、左右腿、头、肩、肘、腕、手指、脊柱、骨盆和重心；遮挡无法确认时必须写不确定。
- `timeline_beats`：按时间段拆解动作，不允许只写“冲刺”“格挡”“被击飞”。
- `force_contact_response`：主动者、接触点、力方向、受力传导、环境响应和稳定结果。
- `performance_intent`：表情、呼吸、视线、节奏和角色心理变化。

## 4. 摄影机与成像

- `camera_position`：机位高度、方位、与角色距离、主观/客观关系。
- `camera_motion`：固定、推、拉、横移、升降、环绕、跟拍、甩镜、震动；必须区分人物接近造成的透视放大。
- `lens_fov`：广角/中焦/长焦倾向，焦段或 FOV 是否变化。
- `focus_depth`：清晰主体、景深、拉焦、焦点呼吸和焦点交接。
- `composition_editing`：景别、构图、轴线、屏幕方向、动作匹配和隐藏切点。

## 5. VFX、光与声音

- `vfx_layers_timing`：每一层特效的来源、形态、方向、出现时间、峰值、衰减与遮挡关系。
- `interactive_lighting`：能量对皮肤、毛发、衣甲、碎石、烟尘和场景的交互光。
- `environment_response`：衣发、尘、烟、碎屑、地面、墙体和背景受力反应。
- `sound_beats`：起势、破风、接触、低频、尾响、音乐留白和进入下一镜的声音桥。

## 6. 审计与重制

- `often_missed`：最容易漏写、误判或被生成模型融合的细节。
- `uncertainties`：无法从当前帧可靠确认的内容，不得用肯定语气编造。
- `rebuild_route`：3D Blocking、角色 ID、Depth、Motion Vector、局部生成、VFX 分层和剪辑方案。
- `source_fidelity_vs_adaptation`：先记录原片事实；目标角色替换与风格化改编单独写，不能污染原片拉片。

## 完整性门槛

每一镜至少回答：

1. 上一镜以什么状态结束？
2. 第一帧谁在什么位置？
3. 谁先动，哪一侧肢体先动？
4. 肩、肘、腕、髋、膝、脚和重心如何传导？
5. 摄影机到底动了，还是人物靠近造成尺寸变化？
6. 焦点和焦段是否变化？
7. 特效从哪里产生，向哪里运动，何时达到峰值？
8. 接触点与受力方向是什么？
9. 最后一帧稳定状态是什么？
10. 下一镜为什么能接上？

任何一项无法确认，都要明确标为 `uncertainties`，不能省略或理所当然补全。
