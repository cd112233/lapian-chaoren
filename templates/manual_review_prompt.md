# 单镜头动作/VFX拉片提示模板

请只分析当前单个镜头，不创造原片中不存在的动作。

输入：镜头首帧、中帧、尾帧、镜头片段、上下镜头结束状态。

输出：

1. 镜头功能：本镜头向观众传递什么。
2. 摄影机：景别、角度、高度、方向、速度曲线、焦点与轴线。
3. 角色 A：起始姿态、主动作、身体联动、结束姿态。
4. 角色 B：起始姿态、响应动作、受力方向、结束姿态。
5. 接触拓扑：谁主动、哪些部位可见、唯一接触点、力量方向、接触发生时段。
6. 镜间因果：上一镜结束 → 决定性变化 → 本镜开始；本镜结束如何接下一镜。
7. 场景：前中后景、固定锚点、可破坏物、光源和空间深度。
8. VFX：按前景/主体接触/背景分层，写出现、峰值、衰减和交互光。
9. 声音：预备声、接触声、身体/兵器拟音、环境响应和尾响。
10. 难度：人物动作、接触、摄影机三维各为 low/medium/high。
11. 重制路线：纯图生视频 / 首尾帧 / 姿态或3D blocking / 视频转视频 / 分层合成。
12. 失败回退：若模型无法完成，如何拆镜、裁切、改 POV 或改为特写。
